# Squeezer v1.1.0

## What's new

- Preferences now save image and video compression defaults locally on this Mac.
- Choose to save results beside each source file, in one fixed folder, or pick a folder for each batch.
- Workspace batch controls and Preferences stay in sync; per-file overrides remain temporary.
- Invalid output folders and cancelled folder selection leave queued work intact.
- Existing files are never overwritten; output names continue with numbered suffixes when needed.

## Notes

- Image and video processing remains local. Original files are not modified.
- Video output remains H.264 MP4. Target size is best effort.
- Metadata controls, HEIC input, HEVC output, and APNG optimization are not included.
- The macOS app is not signed or notarized. macOS may show a security warning when opening it.
