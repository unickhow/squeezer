# Squeezer v1.1.1

## Fixes

- Fixed PNG compression incorrectly failing when the source had an alpha channel but contained no transparent pixels.
- PNG files with actual transparency continue to be checked before the compressed output is accepted.

## Notes

- Image and video processing remains local. Original files are not modified.
- The macOS app is not signed or notarized. macOS may show a security warning when opening it.
